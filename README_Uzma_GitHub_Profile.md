## ⟡ Featured project

### [Obfuscation Toolkit](https://github.com/uzmabibi123/obfuscation_toolkit)

A Python-based toolkit for experimenting with URL and text obfuscation, then identifying and decoding obfuscated input.

- Implements **11+** URL and text obfuscation techniques.
- Includes an analyzer with pattern-based detection, confidence scoring, and recursive layer analysis.
- Uses a modular structure for URL processing, text processing, and analysis.
- Designed for authorized security testing and awareness training.
